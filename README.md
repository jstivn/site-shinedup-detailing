## ⚡ Cloudflare Pages & Global Edge Deployment

This project is fully configured for Cloudflare Workers & Pages:

1. Push to GitHub (`jstivn/site-shinedup-detailing`).
2. In Cloudflare Dashboard, connect the `site-shinedup-detailing` repository.
3. Configure build settings:
   - **Framework:** `None`
   - **Build command:** *(leave empty or `node build.js`)*
   - **Output directory:** `dist` or root `/`
4. Deploy globally across 330+ Cloudflare edge data centers.
